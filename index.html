Selected work

Health checks that don't lie

ODS · open source · Python, JSON Schema, Bash

ODS assumed every service spoke HTTP. Anything exposing only TCP or a CLI failed its health check, got marked dead, and vanished from the dashboard without an error anyone would ever see. Silent data loss, essentially, but for services.

I threaded a health_type: http|tcp|none field through the entire stack: JSON schema, catalog generator, dashboard API, and the shell scripts underneath. The interesting part wasn't the feature. It was the migration. Dozens of existing service manifests had to keep working untouched, so the default had to infer correctly from what each one already declared.

Also merged in the same codebase: a node diagnostics endpoint for runtime hardware introspection, gpu_backends schema validation, and compatibility blocks across 25 manifests.

Agents that think without talking

LatentMAS-SLoRA · PyTorch, PEFT, Qwen2.5-VL, RunPod

Multi-agent systems waste a lot of money re-serializing thoughts into English so the next agent can parse them back out. The LatentMAS paper (ICML 2026 Spotlight, arXiv:2511.20639) showed you can skip that step and pass hidden states directly between agents.

I extended it with role-specialized LoRA adapters that hot-swap at runtime, so one base model plays Planner, Critic, Refiner, and Judger without holding four sets of weights in VRAM. The Critic and Refiner never emit a token, roughly 200ms each. It ships with vision-language support on Qwen2.5-VL-7B, RAG integration, and a RunPod serverless deployment with CI/CD.

The paper's authors added it to their README as community extension #5, alongside work from MIT's LAMM group. There's a demo video.

The README is equally clear about what it isn't: PEFT-based adapter management rather than true S-LoRA, with no custom CUDA paging kernels and no heterogeneous batching. Throughput benchmarks against vLLM S-LoRA are on the roadmap, not done. I'd rather you read that here than find it out on a call.

Making rented GPUs behave

ODS · Bash, Docker Compose, Vast.ai

GPU marketplaces hand you a box that is technically the card you paid for and broken in a dozen quiet ways. Wrong driver version, missing ACLs, a container runtime that was never wired up properly.

I wrote a multi-phase hardened installer for it: set -euo pipefail throughout, hard-fail ACL checks, GPU-tier detection, and around 28 documented host-environment failure modes with the fix for each one. The documentation was most of the value here. Anyone can write the happy path.

A broker so agents can rent their own GPUs

gpu-broker-mcp · MCP, Python, Streamable HTTP

A stateless MCP server that lets an agent discover nodes, reserve capacity, dispatch inference, and poll for results through four tools, without ever handling SSH keys, node IPs, or provider APIs itself. Stateless by design, so there are no sessions to lose and no sticky routing to get wrong.
